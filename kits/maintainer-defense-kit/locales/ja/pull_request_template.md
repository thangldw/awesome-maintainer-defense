## 承認された範囲

Issue または maintainer request をリンクし、限定された成果を記載します。

## 証拠

再現手順、test、正確な検証 command を示し、未解決の制約を明記します。

## 権限と影響

Workflow permission、外部 data flow、コントリビューターに見える操作、setting change を列挙します。該当しない場合は `なし` と記載します。

## ロールバック

Owner と正確な revert または disable 操作を記載します。

## 人による承認

- [ ] 責任を持つ人が変更を理解して承認しました。
- [ ] Automated assistance を確認し、policy に従って開示しました。
- [ ] Secret、personal data、private vulnerability detail を含みません。
- [ ] Test が変更動作と rollback を対象にしています。
