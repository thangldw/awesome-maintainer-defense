# Maintainer defense 導入記録

- Repository と commit:
- Owner:
- 導入日:
- Profile（`observe`、`balanced`、`hardened`）:
- Signal window と標本方法:
- Rule または signal ごとの findings:
- False positives と未解決項目:
- Appeals と結果:
- Threshold decision と承認者:
- Permissions と外部データ送信先:
- コントリビューターに見える効果:
- Rollback trigger と正確な操作:
- 次回 review date:

## 判断の証拠

機密情報を除いた report、test run、owner 承認をリンクします。Credential、private report、判断に不要な contributor identity data は記録しません。
