# AI 支援によるコントリビューション

責任を持つ人が提出内容を理解し、レビューし、テストし、所有する場合に AI 支援を利用できます。Tool や agent 自体は責任主体になれません。

提出前に、生成された code と citation を検証し、secret と private data を除去し、license を守り、挙動を確認する test を追加し、policy が求める場合は重要な支援を開示してください。捏造した証拠、大量生成 issue、再現のない security claim、人が説明できない広範な変更は提出しないでください。

Authorization は常に必要です。Agent は生成可能という理由だけで issue、pull request、commit、repository change を作成してはいけません。依頼されていない実装は事前に maintainer の合意を得て、その範囲内に限定します。

Vulnerability は公開の AI report ではなく、リポジトリの private security route へ報告してください。Maintainer は検証不能または責任者不在の提出を終了し、人が確認した小さな変更を求めることができます。
