# AI-assisted contributions

AI assistance is allowed when an accountable human understands, reviews, tests, and owns the submission. A tool or agent cannot be the responsible contributor.

Before submission, verify generated code and citations, remove secrets and private data, comply with licenses, add behavior-focused tests, and disclose substantial assistance when project policy requests it. Do not submit fabricated evidence, generated issue floods, security claims without reproduction, or broad changes that no human can defend in review.

Authorization still applies. An agent must not open an issue, pull request, commit, or repository change merely because it can generate one. Obtain maintainer agreement for unsolicited implementation and keep scope within that agreement.

Report suspected vulnerabilities through the repository's private security route, not through a public AI-generated report. Maintainers may close unverifiable or unowned submissions and request a smaller human-reviewed change.
