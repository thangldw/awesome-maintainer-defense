# Tài liệu tiếng Việt

Tiếng Anh là hợp đồng sản phẩm canonical. Bộ tiếng Việt trình bày các bước thiết yếu để chạy auditor, hiểu giới hạn an toàn, vận hành control và tham gia pilot.

| Nhu cầu | Tài liệu |
| --- | --- |
| Chạy audit đầu tiên | [Bắt đầu](GETTING_STARTED.md) |
| Hiểu ranh giới và giới hạn | [An toàn](SAFETY.md) |
| Triage, phê duyệt, rollout và rollback | [Playbook](PLAYBOOK.md) |
| Quyền hạn và consent của pilot | [Pilot](PILOTS.md) |

Chi tiết đầy đủ và machine contract nằm trong [tài liệu English](../README.md). [Security](../../SECURITY.md), [Support](../../SUPPORT.md), [Privacy](../../PRIVACY.md), [Terms](../../TERMS.md) và [License](../../LICENSE) bằng tiếng Anh là canonical; bản dịch không thay thế hoặc mở rộng các điều khoản đó.

Sơ đồ canonical bằng English: [ranh giới tin cậy](../diagrams/trust-boundaries.html), [từ audit đến hành động](../diagrams/audit-to-action.html), và [từ consent đến evidence](../diagrams/consent-to-evidence.html). Các trang an toàn và pilot bên dưới có mô tả tương đương bằng tiếng Việt.
