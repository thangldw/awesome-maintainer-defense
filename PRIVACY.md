# Privacy Policy

Last updated: 2026-08-02

Awesome Maintainer Defense and its bundled plugin run locally. They do not operate a hosted service, create user accounts, collect telemetry, or transmit repository contents, audit results, credentials, or personal data to the project author.

The auditor reads repository policy files, Git metadata, and GitHub Actions workflow files within the directory selected by the user. It may inspect the configured Git remote locally to identify an `OWNER/REPOSITORY` value. It does not contact GitHub or another network service during an audit.

Output is printed locally or written to a path explicitly selected by the user. Users control retention by deleting reports and generated patch files. For privacy questions, open an issue at https://github.com/thangldw/awesome-maintainer-defense/issues.
